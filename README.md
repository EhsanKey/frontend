# بویلرپلیت اختصاصی پنل مدیریت و داشبورد (Next.js 16 + HeroUI + React 19)

این مخزن یک **بویلرپلیت و استارترکیت کامل، ماژولار و آماده اجرا** است که بر پایه معماری مدرن Next.js App Router و کامپوننت‌های HeroUI طراحی شده است. تمام زیرساخت‌های لازم (احراز هویت، کنترل دسترسی، لایوت واکنش‌گرا، جداول هوشمند داده، فرم‌ها و لایه API) پیاده‌سازی شده و نیازی به تغییر در هسته پروژه نیست.

---

## 🚀 ویژگی‌های کلیدی

- **Next.js 16 (App Router)** به همراه **React 19** و **TypeScript**.
- **HeroUI v3** و **Tailwind CSS v4** با استایل‌های مدرن و راست‌چین (RTL).
- **سیستم احراز هویت امن (BFF Pattern)** با کوکی‌های HttpOnly و لایه پروکسی `/api/backend/*`.
- **قابلیت اجرای فوری و مستقل (Mock Data Engine)** بدون نیاز به بک‌اند خارجی جهت تست و مشاهده آنی.
- **کنترل سطح دسترسی بر پایه نقش (RoleGuard)** برای صفحات و کامپوننت‌ها (نقش‌های ADMIN و USER).
- **لایوت کامل داشبورد**: سایدبار دسکتاپ جمع‌شونده (Collapsible)، دراور موبایل، هدر همراه با مشخصات کاربر و منوی پروفایل/خروج.
- **سیستم پیشرفته جداول داده (`TableContainer`)**:
  - صفحه‌بندی دوجهته فارسی
  - جستجو و فیلترهای هماهنگ با URL Query Params (`useQueryState`)
  - اسکلتون‌های لودینگ خودکار
  - وضعیت‌های Empty و Error
- **سیستم اعتبارسنجی فرم‌ها**: یکپارچگی `react-hook-form` با اعتبارسنجی قوی `zod`.
- **معماری تمیز لایه سرویس (Clean Service Architecture)**: جداسازی کامل DTO، Mapper، Endpoint و Service با الگوی **Server Module Pattern**.
- **بومی‌سازی و چندزبانه**: با `next-intl` و پشتیبانی پیش‌فرض از زبان فارسی و فونت وزیرمتن.

---

## 📦 راه‌اندازی سریع و اجرا

### ۱. نصب وابستگی‌ها
در پوشه این پروژه دستور زیر را اجرا کنید:
```bash
pnpm install
```
*(یا با `npm install` / `yarn`)*

### ۲. اجرای سرور توسعه
```bash
pnpm dev
```
سپس مرورگر خود را در آدرس [http://localhost:3000](http://localhost:3000) باز کنید.

---

## 🔑 ورود به سیستم و حساب‌های دمو

پروژه به صورت پیش‌فرض دارای یک موتور Mock داخلی است؛ در صفحه ورود می‌توانید:
1. روی دکمه **«⚡ ورود سریع با کاربر دمو (مدیر)»** کلیک کنید تا با نقش `ADMIN` وارد داشبورد شوید.
2. یا روی دکمه **«👤 ورود سریع با کاربر معمولی»** کلیک کنید تا با نقش `USER` وارد شده و تفاوت دسترسی‌ها را تست کنید.

---

## 🔌 اتصال به بک‌اند واقعی (Real Backend)

برای اتصال این پنل به API واقعی پروژه خود، کافی است فایل `.env.local` را باز کرده و آدرس سرور خود را وارد کنید:

```env
API_BASE_URL=https://api.yourdomain.com/v1
```

با این کار:
- لایه پراکسی Next.js تمامی درخواست‌های `/api/backend/*` را مستقیماً به سرور شما فوروارد می‌کند.
- توکن ورود به صورت خودکار در هدر `Authorization: Bearer <token>` برای بک‌اند شما ارسال می‌شود.
